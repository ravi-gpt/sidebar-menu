Sidebar Menu:
A responsive and modern sidebar navigation menu built using HTML and CSS. This project features a clean user interface, interactive navigation links, hover effects, and a visually appealing layout designed to provide a simple and user-friendly browsing experience.

✨ Features
Responsive sidebar navigation
Clean and modern UI
Interactive hover effects
Navigation menu with icons
Simple and organized layout
Built with pure HTML and CSS

🛠️ Technologies Used
HTML5
CSS3

How to Run
Download or clone this repository.
Open the project folder.
Open `index.html` in your browser.

📌 Project Purpose
This project was created to practice HTML and CSS layout, navigation menus, styling, hover effects, and responsive web design.
